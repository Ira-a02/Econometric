# Эконометрика

Учебные работы по эконометрике на языке R с использованием реальных данных (банки, макроэкономика, временные ряды).

### Что реализовано:
- Парная и множественная регрессия, проверка предпосылок МНК.
- Тесты на гетероскедастичность (Бреуша-Пагана, Гольдфельда-Квандта) и автокорреляцию (Дарбина-Уотсона).
- Проверка мультиколлинеарности (VIF, матрицы корреляций).
- Анализ временных рядов: декомпозиция, тест Дики-Фуллера, ACF, прогнозирование.

### Инструменты:
Язык R, RStudio, пакеты lm, plm, tseries, forecast.

### Примечание:
Файлы представлены в формате DOCX (отчеты с графиками и таблицами). Исходный код на R доступен по запросу.
